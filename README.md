# 🍽️ Banquet Analyzer (Анализ банкетов)

Десктопное приложение на Python для автоматизации подсчёта данных из Excel-файлов с расписанием новогодних банкетов.

## 📌 Текущий статус
На данный момент реализован пользовательский интерфейс (GUI):
- Выбор нескольких `.xlsx` файлов через диалоговое окно.
- Визуальное подтверждение успешного выбора файлов.
- Заготовка для кнопки «Обработать» (логика будет добавлена позже).

## 🛠️ Технологии
- **Python 3.14+**
- **CustomTkinter** — для современного графического интерфейса.
- **Pandas** / **Openpyxl** — (планируется) для чтения и агрегации данных из Excel.
